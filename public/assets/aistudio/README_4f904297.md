# Bridge Builder Pecahan — Paket aset individual SAKTI

Berisi **98 objek gambar terpisah**. Satu objek = satu file `.png` dan `.webp`. Objek vector juga memiliki `.svg` yang bisa diedit. Semua item transparan kecuali dua latar (`latar_sungai`, `latar_air_terjun`).

## Folder
- `karakter/utama_3d/`: empat karakter utama 3D beresolusi 1254×1254.
- `karakter/variasi_3d/`: varian efek visual 3D (bukan perubahan pose anatomi).
- `karakter/pose_vektor_opsional/`: pose berjalan, diam, senang dan berpikir gaya **2D**, berbeda dari render 3D utama, untuk opsi animasi sederhana.
- `jembatan/papan_pecahan/`: papan panjang 1, 1/2, 1/3, 1/4, 1/5, 1/6, 1/8.
- `jembatan/papan_rasio/`: papan merah dan biru ukuran satuan penyebut 2,3,4,5,6,8.
- `jembatan/struktur/`: penyangga, tiang batu, pagar tali, target, jembatan lengkap.
- `lingkungan/`: tebing kiri/kanan, pohon, awan, semak, latar sungai dan air terjun, dll.
- `item_hadiah/`, `ui/`, `efek/`, `audio/`.
- `aturan/aturan_bermain.json`: definisi game + 12 level dan rumus validasi.
- `aturan/game_logic.js`: evaluator referensi untuk integrasi browser.
- `manifest_aset.json`: indeks jalur semua aset.
- `galeri_aset.html`: katalog offline untuk melihat semua gambar dan unduh satu per satu.

## Rasio ukuran pecahan
Lebar papan asli didesain konsisten: `720 × pembilang / penyebut` px (papan satuan semuanya 1/n). Contoh: 1/2 = 360 px, 1/4 = 180 px. Skala semuanya dengan faktor seragam pada perangkat. **Nilai pecahan harus diperiksa memakai integer, bukan membandingkan piksel.**

## Cara integrasi
1. Ekstrak ZIP dengan struktur folder asli.
2. Buka `galeri_aset.html` untuk melihat setiap file dan mengunduhnya.
3. Baca `aturan/aturan_bermain.json`, dan pasang `aturan/game_logic.js` di aplikasi SAKTI.
4. Tampilkan level berurut. Untuk rasio validasi jumlah merah-biru; untuk penjumlahan validasi tiap kelompok suku; untuk pengurangan validasi papan yang dihapus.
5. Opsi penyimpanan sementara: localStorage. Supabase perlu dihubungkan terpisah; paket ini tidak melakukan koneksi internet.

## Prinsip penggunaan
- Tombol UI mempunyai ikon tetapi tidak otomatis berfungsi; hubungkan event handler sendiri.
- Audio adalah bunyi sintesis orisinal dan dapat dinonaktifkan.
- Aset 3D adalah gambar statis, **bukan model 3D GLB/FBX**; variasi ber-efek bukan animasi skeletal.
- `jembatan_selesai` hanya dekorasi hasil; papan yang dipasang siswa harus memakai potongan pecahan modular.
